# Cosmos – the file app that stores everything
Jetpack Compose, edge-to-edge immersive, haptics on every tap, animated stamps and cosmic hero.

## Publish from Termux
    termux-setup-storage
    cp /sdcard/Download/Cosmos.zip ~ && unzip Cosmos.zip && cd Cosmos
    bash publish.sh
GitHub Actions builds the APK -> Releases tab (Cosmos.apk).
